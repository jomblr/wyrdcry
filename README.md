# Wyrdcry

Rules website for **Wyrdcry** — a fast-paced tabletop skirmish game set in the City of the Damned.

The site hosts the full ruleset, warband factions, campaign rules, and an interactive
warband builder. It is built with [Docusaurus](https://docusaurus.io/) and deploys as a
static site — there is no backend, and the warband builder stores everything in the
browser's local storage.

## Quick start

Requires Node.js ≥ 20.

```bash
npm install
npm run start
```

See [SETUP.md](SETUP.md) for the full setup guide and troubleshooting.

## Repository layout

| Path | Contents |
|------|----------|
| `docs/` | Rules, warbands, and campaign content as Markdown/MDX. Sidebars are autogenerated per top-level folder (see `sidebars.js`) |
| `blog/` | Playtest updates, surfaced in the navbar as "Updates" |
| `src/data/` | **Single source of truth for all game data** — fighters, weapons, items, factions, abilities, cost profiles. See [src/data/README.md](src/data/README.md) |
| `src/components/WarbandBuilder/` | The warband builder at `/warband-builder` — a client-side app rendered inside the site |
| `src/components/wiki/` | Components that render weapon, armour, and faction tables from `src/data/` into MDX pages |
| `src/theme/` | Swizzled Docusaurus theme components |
| `static/forge/` | **WyrdForge** — a standalone authoring tool for balancing game data. Plain HTML/JS, served at `/forge` |
| `static/files/` | Downloadable PDFs (rulebook, reference sheet, roster) |

## Game data

`src/data/*.json` is the single source of truth. Both the warband builder and the
wiki tables read from it directly.

WyrdForge does not read those files in place — `scripts/copy-forge-data.js` copies them
into `static/forge/data/` (generated, gitignored) before every `start` and `build`. If
you edit game data, restart the dev server so the sandbox picks up the change.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run start` | Dev server on http://localhost:3000 |
| `npm run build` | Production build into `build/` |
| `npm run serve` | Serve the production build locally |
| `npm run typecheck` | Type-check the TypeScript sources without emitting |
| `npm run clear` | Clear the Docusaurus cache |
| `npm run copy:forge-data` | Refresh the WyrdForge data copy (runs automatically on start/build) |
| `npm run pdf` | Render the docs to `wyrdcry.pdf` (macOS-specific, see SETUP.md) |
