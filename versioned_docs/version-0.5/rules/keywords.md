# Keywords
## Racial Keywords
These keywords are primarily used when a fighter gains Renown and makes a characteristic increase, but are sometimes used for special rules such as hatred.
## Faction Keywords
- `Witch Hunters`
- `Sisters of Sigmar`
- `Mercenaries`
- `Skaven`
- `Possessed`
- `Undead`
- `Hired Sword`
## Fighter Keywords
- <span Id='Leader'>`Leader`</span>
	- Friendly fighters within 6" can use the Leader's Bravery characteristic when taking [Panic tests.](./the-combat-phase/panic.md)
	- If killed, a [new leader must be selected](../campaigns/aftermath-sequence.md#death-of-a-leader)
- <span Id='Hero'>`Hero`</span>
	- Can use equipment marked with <HeroOnly />
	- Can make a [Heroic Reaction](./the-combat-phase/reactions.md#heroic-reaction) once per battle
	- Can make a characteristics increase or select a trait when [gaining renown](../campaigns/renown.md)
	- Can be sent to find items at the Trading Post
	- Must roll on the [Hero Injury Table](../campaigns/aftermath-sequence.md#hero-injuries) when taken out of action
- <span Id='Wizard'>`Wizard`</span>
	- Can use magical abilities
	- Can make the [Channel Magic](./the-combat-phase/actions/channel-magic.md) action
	- Cannot be equipped with armour
- <span Id='Henchman'>`Henchman`</span>
	- Can make a characteristics increase when [gaining renown](../campaigns/renown.md)
	- Becomes a `hero` when reaching 4 renown
	- Must roll on the [Henchman Injury Table](../campaigns/aftermath-sequence.md#henchman-injuries) when taken out of action
- <span Id='Beast'>`Beast`</span>
	- Never gain experience or renown
	- Cannot make scenario actions
	- Cannot be given equipment, but uses [natural weapons](../warbands/Equipment/weapons.mdx#natural-weapons)
