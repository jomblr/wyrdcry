# The Reserve Phase
---

In this phase, fighters in **reserve search parties** are deployed to the battlefield. The deployment map will indicate which search parties come into play, and in which battle round they arrive.

![](/img/map_chance-encounter.png)

Starting with the player with initiative, each player deploys the reserve search parties that arrive this battle round. Fighters must be placed wholly within 3" of their deployment point on the battlefield floor.

Some deployment maps have reserve deployment points that are situated off the battlefield. In these cases, there will be a deployment line next to that deployment point. If a deployment point has a **deployment line**, fighters from that search party must be placed wholly within 3" of the marked portion of the battlefield edge, on the battlefield floor.

If it is ever impossible to place all the fighters from a reserve search party (for example, due to the positions of terrain or enemy fighters), each fighter from that search party must be placed one at a time, as close as possible to their deployment point (if it is on the battlefield map) or deployment line.
