# The Reserve Phase
---

During the reserve phase, fighters in reserve search parties are set up on the battlefield. The deployment map will indicate which search parties come into play, where they will be deployed and in which battle round they arrive.

![](/img/map_chance-encounter.png)

Starting with the player with the initiative, players set up the fighters from the search parties that are coming into play in that battle round wholly within 3" horizontally of their **deployment point.**

Some deployment maps have reserve deployment points that are situated outside the battlefield. In these cases, there will be a **deployment line** next to that deployment point, and fighters from that search party must be set up wholly within 3" horizontally of the marked portion of the battlefield edge.

If it is ever impossible to set up all the fighters from a reserve search party (for example, due to the positions of enemy fighters), each fighter from that search party must be set up one at a time, as close as possible to their deployment point (if it is on the battlefield map) or deployment line.
