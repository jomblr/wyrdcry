## Warband size
---

## Faction rules
---

:::inverse
### Blood of Von Carstein
Each time a `VAMPIRE` earns renown, you can pick from the following abilities in addition to the specializations in the campaign book. Doing so does not count against a fighter’s specialization limit.

### [Trait] Dark Allure
When this fighter makes melee attack actions, enemy fighters cannot make reactions unless they pass a Bravery test.

### [Trait] Blood of Von Carstein
This fighter can use multiple abilities in each activation. The same ability can be used more than once, but abilities that grant free actions must be fully resolved before another ability can be used.

### [Reaction] Transfixing Glare
Use this reaction when a visible enemy fighter within 6" of this fighter uses an action. That fighter must take a Bravery test. If the test fails, they must forfeit that action.

### [Double] Blood-maddened Frenzy
A fighter can only use this ability if an enemy fighter has been taken down by an attack action made by this fighter this activation. This fighter makes a free attack action.

### [Double] Bat Form
For this fighter’s next move action, increase its Move characteristic by 3. During that move action, this fighter can fly.

### [Double] Thrill of the hunt
If the next melee attack action made by this fighter this activation targets a wounded enemy fighter, add 2 to the Attacks and Fight characteristics of that attack action.
:::

:::info
## Thralls
Fighters with the `Thrall` keyword are bound to the `Vampire` leading the warband. A `thrall` cannot be equipped with any weapons, armour or equipment. They do not earn experience or gain renown, are unable to carry treasure tokens and automatically pass any Bravery test they are required to take.
:::
