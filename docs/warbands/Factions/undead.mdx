## Faction rules
---

:::inverse
## Blood of Von Carstein
Each time a `VAMPIRE` earns renown, you can pick from the following heroic talents in addition to the talent groups in the campaign book. Doing so does not count against a fighter’s talent group limit.

### [Trait] Dark Allure
When this fighter makes melee attack actions, enemy fighters cannot make reactions unless they pass a Bravery test.

### [Trait] Royal Blood
This fighter can use multiple abilities in each activation. The same ability can be used more than once, but abilities that grant free actions must be fully resolved before another ability can be used.

### [Trait] Thrill of the hunt
When this fighter uses the 'Onslaught' ability, if the target is wounded, increase this fighter's Attacks characteristic by 2 instead of 1.

### [Reaction] Transfixing Glare
Use this reaction when a visible enemy fighter within 6" of this fighter uses an action. That fighter must take a Bravery test. If the test fails, they must forfeit that action.

### [Double] Bat Form
For this fighter’s next move action, add 3 to its Move characteristic. During that move action, this fighter can fly.

### [Triple] Blood-maddened Frenzy
A fighter can only use this ability if an enemy fighter has been taken down by an attack action made by this fighter this activation. This fighter makes a free attack action.
:::

:::info
## Thralls
A `thrall` cannot be equipped with any weapons, armour or equipment. They do not earn renown, and automatically pass any Bravery test they are required to take.

When a THRALL is activated while their warband is wavering, you must allocate 2 damage points to them.
:::
